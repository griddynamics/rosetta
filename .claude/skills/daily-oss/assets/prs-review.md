# Overall goal

1. Critically review PRs, comments, linked issues/stories, comments there to confirm and validate understanding of the problem and solution.

2. Optionally: add comment and tag author of the PR if you found important information to add, etc. If you need clarifications yourself - just ask advisor and then me.

3. Your task is to fully review those PRs: 
   - Load project context in each subagent
   - You must check if PR and linked issue were even needed and whether solution is addressing the right problem
   - You must identify is there a better, cheaper, faster, cleaner solution
   - You must validate it all works
   - You must search for keywords/tech/etc in the repo
   - You must check that protocol was fully completed
   - You must double check if anything is missing, not covered, lost, conflicting, gaps, inconsistencies
   - You must double check what consequences this implementation leads to
   - If there are any concerns or uncertainties for the PR/issue itself - ask advisor, then comment author
   - Is this project using docs/requirements? Where those updated too?
   - Ensure this PR matches all requirements including test coverage
   - Check if any useless meta-commentary and explanation of the change is present outside of the predefined changelogs (just state true facts, remove false facts, instead of MORE content)
   - Was ALL documentation updated?
   - Are there any alignment issues?

4. Identify if those could be approved by AI:
   - If it is already assigned to me -> skip.
   - If it actually requires human review and inputs -> ask advisor, then user.
   - If there are unknown or it leads to INCREASING risks -> identify better solutions -> ask advisor, then comment author.
   - If it is not passing checks above or it is not fully ready and requires more work -> request for changes.
   - If you have any concerns -> do not approve, ask advisor, then ask user.
   - If it is clear, rather small, and honestly AI can handle it autonomously itself -> approve it yourself.
   - If it is clear that is noise / nitpicking -> ask advisor, then comment author, if absolutely sure -> close it with comment.

5. Merge Approved PRs

# REMEMBER

There is no urgency to get things merged, instead we are looking for high quality solutions and your deep understanding.
