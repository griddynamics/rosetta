| 38 | 2026-11-18 | **POC redesigned to the agreed flow (results page, Part 4).** Each run has two stops: before the first code edit the agent is asked "List the requirements you are about to implement."; at its first "done" the code is saved, each checklist item is checked, and the agent is asked "List anything that is not done or that you did not verify."
