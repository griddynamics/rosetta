# Self Help Workflow (deprecated)

`self-help-flow` is deprecated. Use [`help-flow`](/rosetta/docs/help-flow/) instead.

The two workflows behave identically. `/self-help-flow` still runs if you invoke it explicitly, but the coding agent will never select it on its own, and it reminds you to switch.
