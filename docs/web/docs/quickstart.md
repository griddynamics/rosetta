# Quick Start

**Install** Rosetta: use [Plugins](/rosetta/docs/plugins/) when your IDE supports a plugin, or [MCPs](/rosetta/docs/mcps/) when you need MCP. For every mode and the bootstrap fallback, see [Installation](/rosetta/docs/installation/).

**Initialize** the repository once: follow [Installation — Initialize Repository](/rosetta/docs/installation/#step-4-initialize-repository).

**Configure** its context and tooling: use [Configuration](/rosetta/docs/configuration/). Then use the [Usage Guide](/rosetta/docs/usage-guide/) for coding, modernization, analysis, and other workflows.
